
## Common Options

- `includeImages`: Boolean switch to include or strip images (mapped to `skipImages` / filter rules).
- `headingStyle`: Style of headers (`atx` vs `setext` / `underlined`).
- `codeBlockStyle`: Code block representation (`indented` vs `fenced` / `backticks`).
- `bulletListMarker` / `bullets`: Unordered list item marker character (`-`, `+`, `*`).
- `emDelimiter` / `strongEmSymbol`: Character used for emphasis/strong delimiters (`*`, `_`).
- `linkStyle`: Link rendering format (`inline` / `inlined` vs `referenced`).

## Turndown-only Options

- `hr`: Horizontal rule syntax (`---`, `***`, etc.).
- `fence`: Specific code block fence marker (```` ``` ```` vs `~~~`).
- `linkReferenceStyle`: Reference link style (`full`, `collapsed`, `shortcut`).
- Separate `emDelimiter` and `strongDelimiter` customization.
